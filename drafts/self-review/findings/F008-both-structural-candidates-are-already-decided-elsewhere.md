# F008 — Both candidates the collision audit left open are already DECIDED elsewhere in the tree, by the two instruments it named
phase: normalization-collision audit (follow-on to F007)   step: n/a   date: 2026-09-03T01:10Z

what happened: F007 settled three of the audit's five open candidates and said the other two — `CAND-TRANSPORT` and `CAND-CROSSARRAY` — should stay `HYPOTHESIS` in that package because neither is reachable from a seed there. That is right, and they have stayed. But "not decidable HERE" is a different statement from "not decided", and the second one is false for both. Each is already decided in this repository, by exactly the instrument the audit's own `why` text predicted would be needed.

**CAND-TRANSPORT is CONFIRMED, by a real socket.** `internal/ac5class/register.go` carries `ac5-collision-server-tcp-close`, class `normalization-collision`, with `Collision{DivergenceID: "DIV-02-server-leaves-tcp-open"}`. Its mechanism paragraph is the same claim the audit's candidate makes, in the register's own words: the oracle vocabulary "has NO transport dimension … Who hangs up is not a field, so both behaviours normalize to the same observation and the differential reads parity." Its witness is a real-socket test that exists: `a_server_closes_the_tcp_connection_once_its_close_echo_has_drained`, at `rust/ws-testee/tests/loopback.rs:1396`, run as `ws-testee --test loopback`. The audit's `why` said the witness "has to be a real peer socket, which is ws-testee's loopback test" — and that test is there, named, and bound.

**CAND-CROSSARRAY is CONFIRMED, by a mutated harness.** The audit's `why` said seeding it "needs a MUTATED harness, which is `cmd/mutctl`'s instrument, not this one." `cmd/mutctl/mutations.go:441` is that mutation: `m013-close-event-order-swap` emits the close event AFTER the transition instead of before. `internal/ac5class/register.go:454` records what it MOVED — `Moves: []string{}`, nothing — with the reason "the normalization projects events[] and transitions[] into separate arrays, so every ordering relation BETWEEN the arrays is erased. It is a second normalization collision, found by this register rather than by a person." A second entry, `cand-event-order-outbound-pair-swap`, reports the same empty result for `emit_outbound`'s own two emissions, and adds the boundary: only a swap of two ADJACENT `events[]` entries is observable at all.

**Why this is a finding and not a correction.** Nothing was overclaimed. The audit's candidates say "Confirmed elsewhere, out of scope here" (CAND-TRANSPORT) and "Reasoned, not run" (CAND-CROSSARRAY), and both stay `HYPOTHESIS` in that package because a package must not import a verdict it did not produce. What is missing is only the CROSS-REFERENCE: a reader of `audit.json` cannot get from `CAND-CROSSARRAY` to `m013-close-event-order-swap`, and the audit's `undecided_candidate_count` reads as two open questions when both are answered files away. The register found one of them itself — its own note says "found by this register rather than by a person" — which is the strongest possible argument that these two artifacts should be able to see each other.

what it cost: nothing yet. The risk it names is double-counting in the other direction: a future reader could re-derive CAND-CROSSARRAY as a NEW collision and report eight, when the register already holds it.

where the deciding moment was: the temptation here was to move both candidates to CONFIRMED in `audit.json` on the strength of reading another package's committed verdicts. That would have been the exact failure the audit exists to refuse — importing a result rather than producing one — and it would have made `normcollide`'s counts depend on `ac5class`'s prose. They stayed `HYPOTHESIS`, and this note carries the cross-reference instead.

bin: not a defect — a missing link. The cheap fix is a `decided_elsewhere` reference on each candidate naming the artifact and the test id, checked against those files so it cannot rot; the wrong fix is a verdict in `audit.json` that no run in `normcollide` produced. Both candidates stay open there either way.
