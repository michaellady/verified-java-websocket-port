# F004 — A race test that bounds its spin by an iteration count assumes the host's scheduling speed
phase: native-thread evidence (nearest: port-link / port-calibrate)   step: n/a   date: 2026-09-02T12:55Z
what happened: `a_producer_racing_the_owner_drop_never_blocks_and_never_reports_a_stale_accept` in `rust/ws-core/tests/concurrency_boundary.rs` spins `try_send` on a producer thread until the owner thread's `drop(queue)` is published, and asserted `refusals_before_the_drop < 4096` as its "never spins unboundedly" guard. Each refusal is one mutex round-trip, so 4096 of them take well under a millisecond on an idle machine; on this Linux host, with a Go suite and cargo builds running beside the gates, the owner thread was descheduled for longer than that and the test failed 2 runs in 5 with `ws-core` byte-identical to mainline. The property the test exists for (bounded capacity, exactly one typed post-drop refusal, terminal reason) was never violated; the failing assertion was a statement about the machine.
what it cost: one red `make -C rust gates` (exit 2 at `test-release`) on the us019-native-run forward merge, and the investigation to show the crate under test had not changed; about twenty minutes.
where the deciding moment was: when the guard against an unbounded spin was written as a count rather than a duration. A count of lock round-trips is a host-speed measurement dressed as a bound (REFERENCE section 4, first form, host variant — the same class as F002's buffer size). The receipt that landed it read green on a quiet arm64 Mac and inside quiet Docker VMs.
evidence: `rust/ws-core/tests/concurrency_boundary.rs` (the loop's comment block and the wall-clock deadline that replaced the count, plus a `thread::yield_now()` after each capacity refusal so the owner thread gets a turn); this branch's forward-merge commit; the gates log of the failed run recorded in the us019-native-run landing preparation in `.claude/GOAL-LOOP.md`.
bin: REDISCOVERY of F002's class (fixture sized to a host), in a different fixture kind: a spin bound instead of a buffer size. The portable rule is the same one F002 proposed, stated once more for time: a fixture's own liveness guard is a generous wall-clock deadline, never a count of how many times a fast machine can do something. Not yet filed against the family.
